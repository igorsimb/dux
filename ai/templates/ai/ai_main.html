How to get a more useful answer

  • Double-check answers: like any AI system, Dux can make mistakes.
  • Include context when possible: the source, table, fields, period, metric, and desired format.
  • If an artist, album, track, customer, or genre name may vary, ask Dux to consider alternative spellings.
  • Dux shows up to 50 rows by default. To see more, specify a number, such as "show 200."
  • If no answer appears or it looks unusual, try asking again.
  • When switching to a substantially different task, start a new chat.
  • If Dux repeats itself, wait a moment. If that does not help, start a new chat.
